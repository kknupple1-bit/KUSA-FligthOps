KUSA FlightOps v5.25.19 — S+Flaps 20° Nomograph Panel Digitization + Shadow Regression

STATUS
Development / validation only. Not approved for flight use.

PURPOSE
Continue the Falcon 50 / N33AP migration from legacy/FlightSafety-derived performance grids to direct Dassault source data without silently relabeling unvalidated data.

DIRECT SOURCE DIGITIZATION COMPLETED IN THIS PHASE
Source: Dassault DTM813, Section 5, §5.45.6 — Balanced Field Length, S + Flaps 20°.

The following nomograph panels are directly digitized into:
  public/data/f50_s20_nomograph_rev31.json

  • Pressure-altitude / ambient-temperature panel — solid anti-ice-OFF curves
  • Takeoff-weight family / crossing panel
  • Runway-slope correction panel
  • Wind correction panel
  • Field-length axis calibration

The dataset is intentionally tagged SHADOW_VALIDATION_ONLY. It does not replace the current production BFL/V1 grid in this revision.

RUNTIME SHADOW ENGINE
A separate browser-side solver loads the source-controlled JSON and computes S+Flaps 20° dry balanced-field length from the directly digitized panel coordinates. It is used only for source migration and regression testing.

IMPORTANT RELEASE LIMIT
Three published numeric anchors are not sufficient to release a continuous nomograph engine for operational TOLD. The current TOLD BFL/V1 grid therefore remains migration-controlled and unchanged. The direct §5.45.6 shadow engine must pass an expanded independent hand-read regression set across pressure altitude, temperature, weight, slope and wind before production activation.
