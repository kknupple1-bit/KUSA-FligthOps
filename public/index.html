6. Performance Evaluation

Automatic performance tables: FlightSafety International Falcon 50 Pilot Checklist Rev 8.4, P-2–P-5 and P-18–P-21. V1, VR=V2, Vfr, 1.5Vs, BFL, VREF and landing field length are automatically interpolated only inside the digitized table ranges. TABLE DATA READY means the published table values were calculated; it does not mean obstacle, climb, or every operational limit has been independently cleared. No extrapolation.
