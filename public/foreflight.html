Set up the Share action

  1. Open Apple Shortcuts, create a shortcut named Create KUSA Trip, enable Show in Share Sheet, and set its input to PDFs. Set no input to Stop and Respond.
  2. Add Count for Shortcut Input, then If Count is not 1: Show Alert “Share one combined Navlog / flight-plan PDF” and Stop This Shortcut.
  3. Add URL and paste the Upload URL above. Use the complete address exactly as provided on this site.
  4. Add Get Contents of URL: Method POST; Headers Content-Type = application/pdf and X-FlightOps-Upload-Key = your upload key; Request Body File = Shortcut Input.
  5. Add Get Dictionary Value: key open_url from Contents of URL. Add If Dictionary Value has any value → Open URLs using that value. Otherwise Show Alert using Contents of URL; do not retry in a loop.
  6. In ForeFlight, choose Share PDF → Create KUSA Trip. Allow the connection to the Upload URL’s host when iPad asks. The browser opens this review screen; sign in if prompted.

Preview’s GoDaddy access layer must also allow the Shortcut request. Use the shared Preview URL on this iPad first. If the Shortcut returns a GoDaddy sign-in page instead of a review link, report it here.

Text-based PDFs only, up to 4 MB / 20 pages. Image-only/scanned or password-protected documents are rejected. Missing or conflicting fields are left for your review. No third-party AI or email service receives the PDF.
