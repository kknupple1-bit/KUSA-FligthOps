KUSA FlightOps v5.23.4

NMS production transition hotfix
- Fixes /api/notams/ping ReferenceError: icao is not defined.
- Restores the FAA production 3-minute per-airport NOTAM cache to /api/notams, where it belongs.
- Prevents the ping route from using airport-cache logic.
- Derives NMS environment from the configured base URL first, preventing a stale NMS_ENVIRONMENT secret from mislabeling a production connection as STAGING.
- Carries forward v5.23.3 draft/CG integrity fixes and v5.23.2 production NOTAM/parser/TOLD sharing work.

GoDaddy production secrets
NMS_AUTH_URL=https://api-nms.aim.faa.gov/v1/auth/token
NMS_BASE_URL=https://api-nms.aim.faa.gov/nmsapi/v1
NMS_RESPONSE_FORMAT=GEOJSON
If an NMS_ENVIRONMENT secret exists it may be set to PRODUCTION, but v5.23.4 derives the displayed environment from NMS_BASE_URL for the known FAA hosts.
